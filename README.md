# Hoffmann & Partners — Law Firm Landing Page

An editorial, typography-first landing page for a European law firm. Designed for trust and authority with a clean professional aesthetic.

## Features

- **Consultation booking modal** — full name, email, phone, legal matter type
- **Practice areas** — 6 specialisation cards (corporate, real estate, litigation, IP, tax, family)
- **Attorney profiles** — team section with credentials and bar admission
- **Client results** — case outcome statistics
- **Trust signals** — years established, cases won, jurisdictions covered
- **FAQ section** — common questions with expand/collapse
- **Mobile menu** — animated slide-in navigation

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
